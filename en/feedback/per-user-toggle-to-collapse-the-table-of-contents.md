Wiki.js 3 can already hide the table of contents, but that setting applies to everyone. Once the TOC is hidden, it’s gone for all readers. There is no way for an individual reader to collapse the TOC for themselves while others keep it.

On pages with wide content, such as tables, code blocks and Mermaid diagrams, the TOC takes up a lot of horizontal space. Some readers want the full width for content, others rely on the TOC to navigate long pages.

Proposed solution:
A collapse/expand button on the TOC panel itself, available to every reader.
Collapsing gives the content area the full width.
The choice is remembered per user (profile setting)
