Wiki.js currently allows users to create custom layouts and content containers through the Markdown editor using custom HTML and CSS. It would be beneficial to have these capabilities built directly into the editors, allowing users to create structured page layouts without writing code.

**Requested Functionality:**
- Flexible Layouts: Arrange, position, and organize content using customizable layouts, including columns and grid structures.
- Content Containers: Group text, images, tables, and other content into visually distinct sections.
- Adjustable Sizing: Customize widths, heights, spacing, and proportions to control how content is displayed.
- Nested Layouts: Allow layouts and content containers to be placed inside one another to create more complex page structures.

The goal is to make creating visually structured and organized pages easier and more accessible without requiring custom HTML or CSS.
