Wiki.js currently allows users to create columns and content containers but only through the markdown editor with custom HTML and CSS. It would be beneficial to have these capabilities built directly into the editors so users can create structured page layouts without writing code for easier organization and simplicity.

**Requested Functionality:**
- Multi-Column Layouts: Easily arrange content into two or more columns.
- Content Containers: Group text, images, tables, and other content into separate sections.
- Adjustable Widths: Allow columns to have equal or custom widths.

The goal is to make creating visually structured pages easier and more accessible without requiring custom HTML and CSS.
