In v2, if you started typing a link ("[" followed by text and then "]"), a popup would show search results for the text between the brackets, and if you selected one, it would complete the link. This was super useful. In v3 currently you have to either know the path (it autocompletes the path, it seems) or you would have to use the tree based browser (having a search option there would be another great idea!)
