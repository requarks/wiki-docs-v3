Hi, and thank you for Wiki.js 3!

The ::block-index block displays each page with its own icon and color, taken from the page properties. It's nice and usefull, for example we use page color to represent its status, so the index gives a nice dynamical overview.

I haven't found a way to get the same result when linking to a single page, or to a hand-picked set of pages. In ::block-links-grid, the icon and color have to be entered manually for each link, so they can get out of sync when the page's properties change. Apologies if I missed an existing way to do this.

Would it be possible to consider something like one of these?

Index block: accept page paths as well as a folder. ::block-index could take the path of one or more individual pages, so a single page can be shown with the same card as in a folder listing.
Links Grid: an option to use the page properties. For internal links, the card could take its icon and color from the linked page. It would be great if it also showed the same arrow as the Index cards, so internal pages look the same in both blocks.
A new Page Grid block that render like the Index block, but with each page path listed manually instead of being read from a folder.

Thanks for considering it.
