It would be nice if there was an option, when creating a new feedback board, to choose a board type, to allow for a board for issues to be created, instead of one for ideas.

All that this would change is the terminology used throughout that board's UI. For example, the "Submit Idea" button would become "Submit Issue".

The terminology used on the Feedback Board creation page would also need to be changed. Any mention of "idea" could simply be replaced with "submission" so that it becomes agnostic to whatever board type is selected.
