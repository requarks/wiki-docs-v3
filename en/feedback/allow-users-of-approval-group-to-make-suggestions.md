It would be nice to have a "require X approvals" mode for the approval system.
The flow could look like this:

- The same group (e.g. users) is allowed to suggest changes for a page and to approve them via an approval rule. The approval rule has a checkbox "always require one approval"
- Users of the specified group see an "suggest edit" button instead of the "edit" button on a page and any other user of the same group can review suggestions.
