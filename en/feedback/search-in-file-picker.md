This is related to this feature request: https://docs.js.wiki/feedback/searching-for-assets-in-the-file-manager

It would be great, if we could search in the file picker itself when we are linking to an existing page. Right now, you need to know where the page is located. And even if you know the exact spot, you have to scroll through a lot of pages to find the one you are looking for.
