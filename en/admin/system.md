# Overview

The System Info page shows information about the server, Wiki.js and the browser you're using.

# Check for Updates

The **Wiki.js** section shows the currently **installed** version and the **latest** version currently available. This check is performed automatically nightly.

> [!TIP]
> You can manually trigger an update check by clicking the **Check / Upgrade** button.

# Information Reported

- The **Client** section lists information about your browser and operating system.
- The **Server Engines** section shows the Node.js and PostgreSQL versions.
- The **Server Host Information** section shows various information about the host server, its specs, the working directory and config path.

# Copy System Info

Click the **Copy System Info** button in the top-right corner of the page to copy all relevant info found on this page.

This is useful when reporting a bug so the Wiki.js developers more easily determine the cause.
