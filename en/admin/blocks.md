> [!NOTE]
> This page is for administrators configuring the content blocks.
> For the guide on how to use them or see the full list of available blocks, refer to the [User Guide Content Blocks](/guide/blocks) page instead.

Wiki.js includes many content blocks for use in pages.

Individual content blocks can be enabled or disabled by using the "**Enabled**" toggle on the right of the desired block. Turning off a block will hide it from Blocks Picker dialog and will strip any use from the rendered page if entered manually.

# Install a Custom Block

From the **Administration Area** :la:arrow-right: **Content Blocks** page, click the **Install Block...** button and select a `.wkblock` file to install.

Once installed, the block can be enabled/disabled like any other block or click the <kbd>:la:trash:</kbd> button to delete it.

> [!TIP]
> Learn how to create your own [custom blocks](/dev/blocks) and optionally share them with the community.
