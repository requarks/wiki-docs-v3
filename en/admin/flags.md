# Overview

The **Flags** page provides an administrator with the ability to enable advanced, debugging or experimental features.

> [!CAUTION]
> **Do NOT enable these flags unless you know what you're doing!**
> Doing so may result in data loss, performance issues or a broken installation!

# System Flags

| Flag | Description |
| :-- | :-- |
| Experimental Features | Enable unstable / unfinished features. **DO NOT** enable in a production environment! |
| Auth Debug | Log detailed debug info of all login / registration attempts. |
| SQL Query Logging | Log all queries made to the database. |
