# Overview

Click the <kbd>:la:code:</kbd> button on the right-most column of a page to view its source code. The source code will be displayed in a dialog.

Click the <kbd>:la:download:</kbd> button in the top-right corner of the dialog to download the page source.

# Permissions

You must have the **View Page Source** (`read:source`) permission in order to use this feature.
