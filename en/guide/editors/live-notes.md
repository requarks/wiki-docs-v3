# Overview

The Live Notes editor is the same experience as the [Markdown editor](/guide/editors/markdown) but with a focus on collaborative note taking.

**Features specific to the Live Notes editor:**

- A random non-guessable path is automatically chosen by default.
- Changes are saved automatically and stored as a continuous history.
- Share the link with other users to write as a team. Users with read-only permissions can watch edits in real-time.
- No access to the File Manager. Uploaded / Pasted images are stored alongside the note.
- Optionaly publish as a normal page at any time.

## Change Access

By default, the live note is in **Editable** access mode.

| Access Mode | Description |
| :-- | :-- |
| Editable | Anybody with the link to the note can edit *(if they have the **Write Live Notes** permission)*. |
| Locked | Anybody with the link can view the note but can't edit. *(if they have the **Read Live Notes** permission)*. |
| Private | Only the creator of the Live Note can view and edit. |
