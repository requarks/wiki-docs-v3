# Overview

As the name implies, redirects are used to redirect the user from one location to another. This is useful if you moved a page and want users visiting the old URL to automatically land on the new page location.

# Interface

The redirection editor interface consists of a simple form:

![Redirection Form](/guide/images/redirect-editor-form.png =800x){.shadow-lg}

- The **Redirect Title** is also the page name. That's how it will appear in the [File Manager](/guide/file-manager).
- The **Target** can be either an internal page to the wiki or an external URL.
- The **Show Interstitial** can be turned on to show a "Redirecting to..." page for a few seconds before going to the target destination. This is useful when you want to signal to the user that they will be redirected and that the behavior is to be expected.
