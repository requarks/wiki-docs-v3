# Description

A short status label in a line of text, such as Beta, New or Deprecated.

# Demo

This badge is using the :block-badge[Default] style, while this one is :block-badge[Solid Red]{color="negative", variant="solid"}. How about an :block-badge[Outlined]{color="positive", variant="outline"} badge?

# Parameters

| Parameter | Default Value | Possible Values |
| :-- | :-- | :-- |
| `color` | `primary` | `primary`, `positive`, `negative`, `warning`, `info` or `grey` |
| `variant` | `soft` | `soft`, `solid` or `outline` |
